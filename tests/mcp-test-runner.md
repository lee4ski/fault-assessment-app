# MCP Visual Test Suite

このドキュメントは、MCPブラウザーツールを使用してアプリケーションを視覚的に検証するためのテストシナリオです。

## テスト実行方法

各テストは、MCPブラウザーツールを使用して手動で実行するか、自動化スクリプトで実行できます。

## テストシナリオ

### Test 1: ホームページの読み込み確認

**目的**: アプリケーションが正しく読み込まれることを確認

**手順**:
1. `http://localhost:3000` にナビゲート
2. ページタイトルが "過失割合計算機 - Fault Assessment Calculator" であることを確認
3. メイン見出し "過失割合計算機" が表示されていることを確認
4. サブタイトル "交通事故の過失割合を効率的に計算するシステム" が表示されていることを確認

**期待結果**: ✅ すべての要素が正しく表示される

---

### Test 2: ワークフローステッパーの表示確認

**目的**: 3つのステップが正しく表示されることを確認

**手順**:
1. ページを読み込む
2. ステップ1 "認定基準の検索" が表示されていることを確認
3. ステップ2 "修正要素の適用" が表示されていることを確認
4. ステップ3 "AI推奨の確認" が表示されていることを確認
5. ステップ番号ボタン（1, 2, 3）が表示されていることを確認

**期待結果**: ✅ すべてのステップが表示される

---

### Test 3: ステップ1 - 検索機能の動作確認

**目的**: 検索機能が正しく動作することを確認

**手順**:
1. ステップ1が表示されていることを確認
2. 検索入力フィールドが表示されていることを確認
3. 検索入力に "交差点" と入力
4. 検索結果に "交差点での歩行者と直進車との事故" が表示されることを確認
5. 検索結果をクリックして選択できることを確認

**期待結果**: ✅ 検索機能が正常に動作し、結果が表示される

---

### Test 4: チャットウィンドウの折りたたみ機能

**目的**: チャットウィンドウが折りたたみ可能であることを確認

**手順**:
1. チャットウィンドウのヘッダー "アシスタントチャット" が表示されていることを確認
2. チャット入力フィールドが表示されていることを確認
3. チャットウィンドウのヘッダーをクリック
4. チャット入力フィールドが非表示になることを確認（折りたたみ）
5. 再度ヘッダーをクリック
6. チャット入力フィールドが再表示されることを確認（展開）

**期待結果**: ✅ チャットウィンドウが正しく折りたたみ/展開される

---

### Test 5: チャット機能の動作確認

**目的**: AIアシスタントチャットが正しく動作することを確認

**手順**:
1. チャットウィンドウが展開されていることを確認
2. 初期メッセージが表示されていることを確認
3. チャット入力フィールドに "検索の方法を教えてください" と入力
4. "送信" ボタンをクリック
5. ローディング状態が表示されることを確認
6. AIからの応答が表示されることを確認

**期待結果**: ✅ チャット機能が正常に動作し、AIが応答する

---

### Test 6: ステップ間の移動

**目的**: ステップ間の移動が正しく動作することを確認

**手順**:
1. ステップ1が表示されていることを確認
2. ステップ2のボタンをクリック
3. "ステップ2: 修正要素の適用と計算" が表示されることを確認
4. "前のステップに戻る" ボタンをクリック
5. ステップ1に戻ることを確認
6. "次のステップへ" ボタンをクリック
7. ステップ2に移動することを確認

**期待結果**: ✅ ステップ間の移動が正常に動作する

---

### Test 7: ステップ2 - 計算機能の動作確認

**目的**: 修正要素の適用と計算が正しく動作することを確認

**手順**:
1. ステップ1で認定基準を選択
2. ステップ2に自動的に移動することを確認
3. 基本過失割合が表示されていることを確認
4. 修正要素のチェックボックスが表示されていることを確認
5. 修正要素を1つ選択
6. 最終過失割合が更新されることを確認
7. "計算結果を保存" ボタンをクリック
8. アラートが表示されることを確認

**期待結果**: ✅ 計算機能が正常に動作する

---

### Test 8: コンソールエラーの確認

**目的**: コンソールに重大なエラーがないことを確認

**手順**:
1. ブラウザのコンソールを開く
2. ページを読み込む
3. エラーメッセージがないことを確認
4. 警告メッセージのみ（React DevToolsなど）であることを確認

**期待結果**: ✅ 重大なエラーがない

---

## 自動テスト実行

MCPブラウザーツールを使用して自動的にテストを実行するには、以下のコマンドを使用します：

```bash
# テストスクリプトを実行（今後実装予定）
npm run test:mcp
```

## テスト結果の記録

各テストの結果を記録し、問題があれば修正してください。
