# MCP Deployment Tests

## 概要

デプロイ前に自動実行されるMCP視覚テストスイートです。以下の項目を検証します：

1. **リンク切れのチェック**
2. **視覚的な正確性（要素の重なりなし）**
3. **チャットエリアの視覚的・機能的動作**
4. **すべてのインタラクティブ要素の動作**

## テスト項目

### Test 1: リンク切れのチェック

**検証内容**:
- すべてのナビゲーションボタンが機能する
- ステップ間の移動が正常に動作する
- 内部リンクが正しく機能する
- ネットワークリクエストで404エラーがない

**実行手順**:
1. ホームページにナビゲート
2. すべてのクリック可能な要素を確認
3. 各ボタンをクリックして動作を確認
4. ネットワークリクエストを監視してエラーを確認

### Test 2: 視覚的なレイアウトチェック

**検証内容**:
- 要素が重なっていない
- 適切な間隔が保たれている
- テキストが読みやすい
- レスポンシブレイアウトが正しい
- ボタンが適切に配置されている

**実行手順**:
1. ページのスナップショットを取得
2. 要素の位置を確認
3. 重なりの有無を確認
4. レスポンシブデザインを確認

### Test 3: チャットエリアの検証

**検証内容**:
- チャットウィンドウが表示される
- 折りたたみ/展開が機能する
- 入力フィールドがアクセス可能
- メッセージ送信が機能する
- AI応答が表示される
- 視覚的な問題がない

**実行手順**:
1. チャットウィンドウの表示を確認
2. 折りたたみ機能をテスト
3. メッセージを送信
4. AI応答を確認
5. 視覚的な問題をチェック

### Test 4: インタラクティブ要素の検証

**検証内容**:
- すべてのボタンがクリック可能
- 入力フィールドが機能する
- フォーム送信が機能する
- ナビゲーションが機能する

**実行手順**:
1. 各ボタンをクリック
2. 入力フィールドにテキストを入力
3. フォーム送信をテスト
4. ナビゲーションをテスト

## 自動実行

これらのテストは、以下のタイミングで自動実行されます：

1. **GitHub Actions**: プッシュ/プルリクエスト時
2. **デプロイ前**: `predeploy` スクリプトで実行
3. **ビルド前**: `prebuild` スクリプトで実行

## テスト結果

テスト結果は `tests/mcp-test-results.json` に保存されます。

## トラブルシューティング

テストが失敗した場合：
1. エラーメッセージを確認
2. ブラウザコンソールを確認
3. ネットワークタブでエラーを確認
4. 視覚的な問題をスクリーンショットで確認
