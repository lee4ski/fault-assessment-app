# MCP Visual Testing Guide

## 概要

MCP (Model Context Protocol) ブラウザーツールを使用して、アプリケーションを視覚的に検証するためのガイドです。

## MCPテストの利点

1. **実際のブラウザ環境**: 実際のブラウザで動作を確認
2. **視覚的検証**: UI要素が正しく表示されることを確認
3. **インタラクティブテスト**: ユーザー操作をシミュレート
4. **エラー検出**: コンソールエラーやレンダリングエラーを検出

## テスト実行方法

### 手動テスト（推奨）

MCPブラウザーツールを使用して、以下のテストを実行します：

1. **ページの読み込み確認**
   ```javascript
   // MCPブラウザーツールで実行
   browser_navigate("http://localhost:3000")
   browser_snapshot() // ページの状態を確認
   ```

2. **要素の存在確認**
   - 見出し、ボタン、入力フィールドが表示されているか
   - テキストが正しく表示されているか

3. **インタラクション確認**
   - ボタンのクリック
   - 入力フィールドへの入力
   - チャットウィンドウの折りたたみ/展開

4. **コンソールエラーの確認**
   ```javascript
   browser_console_messages() // エラーメッセージを確認
   ```

### 自動テストスクリプト

```bash
# テストシナリオの説明を表示
npm run test:mcp
```

2. ✅ ワークフローステッパーの表示
3. ✅ 検索機能の動作

6. ✅ コンソールエラーの確認

## トラブルシューティング

### ページが読み込まれない
- 開発サーバーが起動しているか確認: `npm run dev`
- ポート番号を確認（通常は3000）

### 要素が見つからない
- ページの読み込みを待つ: `browser_wait_for(time: 3)`
- スナップショットを確認して要素の状態を確認

### コンソールエラーが表示される
- エラーメッセージの内容を確認
- 依存関係が正しくインストールされているか確認: `npm install`

## 継続的なテスト

MCPテストは、以下のタイミングで実行することを推奨します：

- 新機能追加後
- UI変更後
- デプロイ前
- バグ修正後
