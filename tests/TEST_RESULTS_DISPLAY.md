# テスト結果表示ページ

## 概要

MCPテスト結果をブラウザで視覚的に確認できるページを作成しました。

## アクセス方法

### 1. メインページから
- メインページの右上に「テスト結果」ボタンがあります
- クリックすると `/test-results` ページに移動します

### 2. 直接URLでアクセス
```
http://localhost:3000/test-results
```

## 機能

### テスト結果の表示

ページには以下の情報が表示されます：

1. **テストサマリー**
   - サーバーアクセス: ✅/❌
   - 必須要素: ✅/⚠️
   - リンク数: 数値表示
   - 視覚的問題: ✅/⚠️
   - 最終更新時刻

2. **詳細結果**
   - サーバーアクセシビリティ
   - 必須要素の確認
   - リンクチェック結果
   - 視覚的な問題
   - エラー一覧（ある場合）

### 操作ボタン

1. **再読み込み**
   - 最新のテスト結果を読み込みます
   - テスト結果ファイルが更新された場合に使用

2. **テストを実行**
   - 新しいテストを実行します
   - 実行中は「実行中...」と表示されます
   - 完了後、結果が自動的に表示されます

## 表示される情報

### 成功時（すべてのテストが通過）

- ✅ すべてのテストが通過しました
- アプリケーションは正常に動作しています。デプロイ可能です。

### 警告時（一部のテストが失敗）

- ⚠️ 一部のテストが失敗しました
- 問題を修正してからデプロイしてください。

### エラー詳細

エラーがある場合、以下の情報が表示されます：
- エラーメッセージ
- 不足している要素
- 視覚的な問題
- リンク切れの数

## API エンドポイント

### GET `/api/test-results`
テスト結果を取得します。

**レスポンス例**:
```json
{
  "timestamp": "2025-11-29T03:17:52.373Z",
  "serverAccessible": true,
  "brokenLinks": {
    "total": 2,
    "broken": 0
  },
  "requiredElements": {
    "allPresent": true,
    "missing": []
  },
  "visualIssues": {
    "hasIssues": false,
    "issues": []
  },
  "errors": []
}
```

### POST `/api/run-tests`
新しいテストを実行します。

**レスポンス**:
テスト結果のJSONオブジェクト（GETと同じ形式）

## テスト結果ファイル

テスト結果は以下のファイルに保存されます：
- `tests/mcp-comprehensive-results.json`

このファイルは、包括的テスト実行時に自動的に更新されます。

## 使用方法

### 1. テスト結果を確認
1. メインページの「テスト結果」ボタンをクリック
2. または `/test-results` に直接アクセス
3. 最新のテスト結果が表示されます

### 2. 新しいテストを実行
1. テスト結果ページで「テストを実行」ボタンをクリック
2. テストが実行されます（約30秒）
3. 完了後、結果が自動的に表示されます

### 3. テスト結果を更新
1. 「再読み込み」ボタンをクリック
2. 最新のテスト結果ファイルから結果を読み込みます

## トラブルシューティング

### テスト結果が表示されない

1. テスト結果ファイルが存在するか確認
   ```bash
   ls tests/mcp-comprehensive-results.json
   ```

2. テストを実行
   ```bash
   npm run test:mcp:comprehensive
   ```

3. ブラウザで再読み込み

### テスト実行が失敗する

1. サーバーが起動しているか確認
   ```bash
   npm run dev
   ```

2. テストスクリプトが存在するか確認
   ```bash
   ls tests/mcp-comprehensive-test.js
   ```

3. エラーメッセージを確認
   - ブラウザのコンソールを確認
   - サーバーログを確認

## デプロイ前の確認

デプロイ前に、テスト結果ページで以下を確認してください：

1. ✅ すべてのテストが通過している
2. ✅ エラーがない
3. ✅ 視覚的な問題がない
4. ✅ リンク切れがない

すべてが ✅ の場合、デプロイ可能です。
